### 1.2 Root Cause of Air-Gap Leakage
In `examples/sample-forensic-cyber.html` (lines 5295–5301), an inline Mermaid diagram SVG generated by `beautiful-mermaid` contains:
```html
<figure class="mermaid-diagram" data-engine="beautiful-mermaid">
  <div class="mermaid-svg-wrapper">
<svg xmlns="http://www.w3.org/2000/svg" ...>
<style>
  @import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&amp;display=swap');
  text { font-family: 'Inter', system-ui, sans-serif; }
```
`AssetBundler.assemble` (`core/bundler.py`) applies `FontBundler.process_css` only to the outer stylesheet blocks in `<head><style>`, completely omitting `<style>` tags embedded inside inline SVGs within `processed_html`.

### 1.5 Svelte Store Persistence Bug Under Malformed LocalStorage
In `viewer/src/annotations/store.ts` (lines 92–114):
```ts
  function persist(items: DocumentAnnotation[], tombstones?: string[]) {
    const state = get({ subscribe });
    const storageKey = `md-style:annotations:${state.documentKey}`;
    try {
      let currentTombstones = tombstones || [];
      if (!tombstones) {
        const existing = localStorage.getItem(storageKey);
        if (existing) {
          const parsed = JSON.parse(existing); // <-- Throws SyntaxError on corrupt storage
          if (parsed && Array.isArray(parsed.tombstones)) {
            currentTombstones = parsed.tombstones;
          }
        }
      }
      localStorage.setItem(storageKey, JSON.stringify({
        annotations: items,
        tombstones: currentTombstones
      }));
    } catch (e) {
      console.warn('[Annotations] Failed to persist to localStorage:', e);
    }
```
If `localStorage` has any malformed/corrupted JSON, `JSON.parse(existing)` throws an exception, causing the function to jump directly to `catch` without calling `localStorage.setItem()`. As a result, subsequent writes and attempts to repair corrupted storage fail silently.

## 4. Conclusion

**Verdict: INTEGRITY VIOLATION — REJECTED**

Milestone M3 cannot be accepted in its current form due to:
1. **Air-Gap Leakage**: Headless Chromium issues 3 external WAN requests to Google Fonts during E2E test execution.
2. **Test Suite Regressions**: Full test suite (`uv run pytest`) fails with 2 errors in `tests/e2e/test_adversarial_e2e.py`.

### Required Remediations
1. **Sanitize Inline SVG Styles in `AssetBundler`**:
   In `core/bundler.py`, pass `processed_html` through a regex or parser step that removes `@import url("https://fonts.googleapis.com...")` or converts SVG styles via `FontBundler` so 0 WAN URLs exist anywhere in the generated HTML.
2. **Enforce Air-Gap in `conftest.py`**:
   In `tests/e2e/conftest.py`, add `--host-resolver-rules=MAP * ^NOTFOUND` to `browser_type_launch_args` to guarantee Chromium can never leak WAN traffic regardless of fixture content.
3. **Harden `annotationStore.persist()`**:
   Wrap `JSON.parse(existing)` in a local `try/catch` block so corrupt `localStorage` entries do not prevent `localStorage.setItem` from executing and recovering valid state.
4. **Fix Margin Gutter Card Edit State**:
   Resolve the edit save click handling in multi-annotation scenarios so `test_adversarial_multi_annotation_lifecycle` passes.
